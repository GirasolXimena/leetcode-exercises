# Move Zeroes

## The problem

Move every zero to the end of an array while preserving the relative order of non-zero values. Modify the input array in place.

## Approach

A write pointer marks the next position for a non-zero value. First compact all non-zero values toward the front, then fill the remaining positions with zeroes. This separates the stable ordering work from the final padding step.

The algorithm takes $O(n)$ time and $O(1)$ extra space. The tests cover empty, all-zero, no-zero, adjacent-zero, and mixed arrays. The benchmark exercises the linear scan with a larger input.
