# Rotate Array

## The problem

Rotate an array to the right by `k` steps in place. Values that move past the end wrap around to the beginning.

## Approach

Only `k % nums.length` steps change the result, so large step counts are normalized first. The implementation builds the rotated order and writes it back into the original array, preserving the in-place API.

The current implementation takes $O(n)$ time and uses $O(n)$ temporary space. Tests cover no rotation, a full rotation, more steps than the length, an empty array, and ordinary examples.
